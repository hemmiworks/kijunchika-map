# 基準地価マップ

国土交通省が公表している都道府県地価調査（基準地価）の全地点を、地図上で見られるようにしたものです。

**地図を開く → https://hemmiworks.github.io/kijunchika-map/**

- 前年比変動率、3年平均変動率（年率）、価格で色分け
- 地点ごとの1983年からの価格推移グラフ
- ランキング、住所・駅名検索
- 背景は地理院タイル（淡色地図）

## ご注意

国土交通省の公表データをもとに作成しています。平均・中央値・3年平均はこの地図独自の集計で、国の公表値とは集計方法が異なります。基準地価は各基準地の標準的な価格で、実際の取引価格や個別の土地の評価額を示すものではありません。地点番号は略記です。

## 出典

- 「国土数値情報（都道府県地価調査データ）」（国土交通省）を加工して作成（CC BY 4.0）
  https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L02-2026.html
- 行政界：国土地理院「地球地図日本」（第2.2版）を加工して作成
- 背景地図：[地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（国土地理院）
- 地図描画：[MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js)（BSD-3-Clause）

## 毎年の更新手順

新しい年のデータ（例：2027年 = `L02-27`）が国土数値情報に掲載されたら、Node.js がある環境で次を実行します。

```bash
bash build/fetch-data.sh 27
cd build
node build-data.js 27
node build.js
```

`docs/index.html` が作り直されるので、コミットしてプッシュすれば公開中の地図が更新されます。

`build-data.js` は、価格履歴の最終年が当年価格と一致するかを全地点で検査します。データの仕様（列番号）が変わった場合はここでエラーになるので、国土数値情報の仕様書を見て列の対応を直してください。

## ファイル構成

| パス | 内容 |
|---|---|
| `docs/index.html` | 公開される地図（GitHub Pages の公開元） |
| `build/template.html` | 地図の本体（HTML・CSS・JS） |
| `build/build-data.js` | 地価データ（GeoJSON）を地図用の軽い形式に変換 |
| `build/build.js` | データと境界を埋め込んで `docs/index.html` を生成 |
| `build/fetch-data.sh` | 国土数値情報から地価データを取得 |
| `build/boundaries.sh` | 地球地図日本から境界データを生成（生成物は同梱済み） |
| `build/pref.geojson`, `build/muni_lines.geojson` | 都道府県・市区町村の境界 |
